# Docker Installation for Windows GPU Benchmarking

## Step 1: Install Docker Desktop for Windows

### Download
1. Go to: https://www.docker.com/products/docker-desktop
2. Click "Download for Windows"
3. Download **Docker Desktop Installer.exe** (choose your architecture: AMD64 or ARM64)

### Installation
1. Run the installer
2. Choose installation options:
   - ✅ Use WSL 2 instead of Hyper-V (recommended for GPU support)
   - ✅ Add shortcut to desktop
3. Complete the installation
4. Restart your computer when prompted

### Verify Installation
```powershell
docker --version
# Should output: Docker version XX.X.X, build XXXXXXX
```

## Step 2: Install NVIDIA Container Toolkit

### In PowerShell (as Administrator):
```powershell
# Enable WSL2 (if not already enabled)
wsl --install

# List WSL distributions
wsl -l
```

### In WSL2 Ubuntu Terminal:
```bash
# Update package list
sudo apt-get update

# Install NVIDIA Container Toolkit
sudo apt-get install -y nvidia-container-toolkit

# Restart Docker daemon
sudo systemctl restart docker
```

### Verify NVIDIA GPU in Container:
```powershell
docker run --rm --gpus all nvidia/cuda:11.2.2-base-ubuntu20.04 nvidia-smi
```

Expected output: Your RTX 3060 GPU information

## Step 3: Build Docker Image

```powershell
cd c:\Users\fanaf\Desktop\Baseline-Native\WebGPU-Study-Baseline

# Build (takes 5-10 minutes)
docker build -t benchmark-gpu:latest .

# Verify
docker images benchmark-gpu
```

## Step 4: Run Benchmark

```powershell
# Ensure results directory exists
mkdir results -ErrorAction SilentlyContinue

# Run all 15 models with 1 trial
docker-compose run --rm benchmark-gpu python3 benchmark_native.py --trials 1
```
